# Free Tools Stack for Organic DTC Growth

Everything here is free (or has a free tier that's genuinely useful).
No paid tools required. The Analytics Agent can generate a brand-specific
setup walkthrough — this doc is the at-a-glance reference.

---

## Search & SEO

| Tool                      | What it's for                                       | Free tier? |
| ------------------------- | --------------------------------------------------- | ---------- |
| Google Search Console     | See which queries drive impressions and clicks      | Fully free |
| Google Analytics 4        | Site sessions, ecommerce events, conversion paths   | Fully free |
| Bing Webmaster Tools      | Index on Bing, free backlink data, keyword research | Fully free |
| Ahrefs Webmaster Tools    | Site audit, backlinks, organic keywords (limited)   | Free tier  |
| Google Keyword Planner    | Search volume + keyword ideas                       | Free (needs a Google Ads account, no spend required) |
| Google Trends             | Seasonal and regional demand                        | Fully free |
| AnswerThePublic           | PAA-style question harvesting                       | Limited free |
| Google PageSpeed Insights | Core Web Vitals + Lighthouse scores                 | Fully free |
| Schema.org Validator      | Validate JSON-LD before publishing                  | Fully free |
| Rich Results Test         | Google's rich-result preview                        | Fully free |

### Start-here routine
1. Verify every brand domain in **Google Search Console** and **Bing Webmaster Tools**
2. Submit your XML sitemap to both
3. Install **GA4** with the standard ecommerce events (`view_item`,
   `add_to_cart`, `begin_checkout`, `purchase`)
4. Run **PageSpeed Insights** on your top 5 landing pages; note LCP and INP
5. Let it run for 2 weeks before drawing any conclusions

## AI Search & generative answer engines

You can't log into these the same way as GSC, but you can observe them:

- **Google AI Overviews** — watch your target queries manually, track
  whether you're cited
- **ChatGPT Search** — ask your brand-relevant queries, see what sources
  it cites
- **Perplexity** — Perplexity Pages shows exactly which URLs it pulls
  from, and you can learn a lot from that
- **Bing Copilot** — same drill as ChatGPT Search

Create a simple spreadsheet: `query | cited | source domain | notes`.
Review weekly. The Technical SEO Agent's `ai-crawler-optimization-guide`
output explains how to make your content more citeable.

## The day-one checklist

If you do nothing else this week:

- [ ] Verify every brand domain in GSC + Bing Webmaster
- [ ] Install GA4 + ecommerce events
- [ ] Install Microsoft Clarity
- [ ] Pick an email ESP and set up double opt-in + a welcome series
- [ ] Claim / optimize your brand on Instagram, TikTok, Pinterest, YouTube
- [ ] Run PageSpeed Insights on your top 5 pages; write down the scores
- [ ] Submit your XML sitemap to GSC + Bing
- [ ] Add a 1-question post-purchase survey

Everything after that is optimization. The Analytics Agent's monthly
review template will tell you what to optimize next.
